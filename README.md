# Primeiro Projeto Machine Learning

## Experiências

Durante a criação do projeto tive algumas barreiras que me impediam de obter o resultado esperado, uma delas foi durante a configuração do Dataset, seguindo o passo a passo foi possivel observar que se tem diferentes tipos de dados, e como não havia verificado, observei que algumas opções como schema não aparecia, com essa nova versão de tipos de dados é importante buscar na documentação e ler a respeito, de forma que possa obter uma melhor experiência

Outro grande pronto foi o script de treinamento, é necessário uma dedicação para entender e elaborar, uma vez que o curso não apresenta de forma elaborada o conteúdo, mostra apenas um guia já pronto e oq cada uma das funções faz, então é importante esse cuidado e detalhe também

## Considerações Finais

A plataforma do Azure é bastante simples e intuitiva, com dedicação e tempo é possível aprender bastante, infelizmente o impeditivo dos créditos é uma barreira, mas gerenciando bem é possível extrair bastante informção
